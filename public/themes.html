Theme or full store build?

A theme gives you a design foundation. A done-for-you store build adds product research, supplier setup, payment integration, copywriting and handover. If you already have a store and only need the design, choose a theme. If you are starting from zero, compare the packages first.

Theme questions

Do I need Shopify to use these themes?
The themes are designed for modern store builders, with Shopify as the primary platform. Message us before buying if you use a different platform.
Can I edit the colors and fonts?
Yes. The theme uses editable sections and global color and font settings so you can match your brand.
Is installation included?
Setup notes are included. Done-for-you installation is available with a store build or as a separate request.
Can I use the theme on more than one store?
A theme purchase covers one store. Contact us for a multi-store license.
